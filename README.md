# 🐍 Snake Game in C

A classic console-based Snake Game developed in C language using basic game development concepts like game loops, collision detection, coordinate systems, and dynamic tail movement.

---

## 🎮 Features

- Real-time snake movement using keyboard controls
- Food generation at random positions
- Snake tail growth after eating food
- Score tracking system
- Wall collision detection
- Self-collision detection
- Smooth console gameplay
- Game Over screen

---

## 🛠 Technologies Used

- C Programming Language
- Windows Console Functions
- `conio.h`
- `windows.h`
- `stdlib.h`
- `time.h`

---

## 🎯 Controls

| Key | Action |
|-----|--------|
| W | Move Up |
| A | Move Left |
| S | Move Down |
| D | Move Right |
| X | Exit Game |

---

## ▶️ How to Run

### Using GCC Compiler

```bash
gcc snake_game.c -o snake
snake
```

---

## 📌 Game Logic

The game works using a continuous game loop:

1. Draw the game board
2. Take user input
3. Update snake position
4. Check collisions
5. Generate food
6. Update score and tail
